# Payment Helper

Android-приложение на Kotlin + Jetpack Compose.

## Сценарий автоматического входа
1. Выберите установленное приложение.
2. Введите пароль для автозаполнения (по умолчанию `olga123`); он хранится только локально.
3. Включите службу специальных возможностей Payment Helper в настройках Android.
4. Нажмите «Перейти» — откроется выбранное банковское приложение.
5. Служба найдёт поле ввода, подставит пароль и нажмёт кнопку «Войти».
6. Приложение вернёт вас в Payment Helper с результатом:
   - «Красава, вход выполнен!» — обнаружен главный экран;
   - «Вход не выполнен: приложение сообщило об ошибке» — банк показал ошибку;
   - «Не удалось подтвердить вход автоматически…» — результат не определён за 120 секунд.

Распознавание экрана эвристическое и зависит от интерфейса конкретного приложения. Пароль приложение не отправляет на сервер и никуда не логирует.

## Сборка
Откройте проект в Android Studio и дождитесь Gradle Sync. Затем выберите Build → Build APK(s).

Если поле входа в банке нестандартное (Compose/WebView) и автозаполнение не срабатывает, скорректируйте findFirstEditable/findSubmitButton в BankAccessibilityService под интерфейс конкретного банка.
